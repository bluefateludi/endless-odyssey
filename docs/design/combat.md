# 战斗与角色成长

首版支持桌面键鼠。WASD 按屏幕方向移动，鼠标指向地面决定挥击朝向，左键普攻，Q 顺劈，E 拾取最近的装备，I 背包，T 天赋。俯视镜头跟随角色，障碍物阻挡移动。技能有效范围与地面提示共用世界坐标。营地是安全区，进入关卡后敌人开始行动。

## 一次命中的结算

普攻前摇 → 有效判定 → 收招。同一挥击对同一敌人最多结算一次。目标在有效判定前走出范围即可避开。怪物动作同样遵守预警与命中窗口。角色死亡即停用输入，显示回营操作，保留已入账成长与装备。

角色基础、天赋和装备的同名属性交由统一解析器计算。物理伤害取「武器掷值 + 攻击力」，乘技能系数，再乘护甲系数 `100 / (100 + 护甲)`；加上附加元素后才乘此次暴击倍率。直接命中、持续伤害和触发伤害带来源标签。持续与触发伤害可击杀并发奖，仅直接命中参与新一次触发判定。装备联动、词条次序与属性上限见[装备规格 §8–9](../../equipment-system-design.md)。

## 经验与反馈

首轮建议基础生命 100、攻击力 4、空手伤害 4–6、攻频 1.4 次/秒、暴击率 5%、暴伤倍率 1.5。当前等级 L 的升级经验为 20 × L，超额经验滚入下一级。每升一级，最大生命增加 8、攻击力增加 1，按天赋规格增加可分配点数。升级或换装提高生命上限时保留当前生命；回营复活补满。同一死亡事件只结算一次。

战斗 HUD 提示当前生命、技能冷却、经验与可用点数；地面预警应能用形状辨识。回归测试固定武器与随机序列，分别核对护甲前后、暴击前后、天赋前后、传奇额外伤害以及重复死亡事件。实玩检查能否通过走位躲开守关 Boss 的重击。
