# 林地关卡、深渊与图鉴

## 首版固定关卡

营地连接一条短林道、一处精英空地与守关石环。入场生成新的遭遇实例，每段敌人全灭后开放下一组。首段四只普通怪各给 5 经验，足以让新角色第一次升级。精英给 16，Boss 给 40。每类敌人使用[装备规格 §6](../../equipment-system-design.md)对应掉落表。胜利后可以先拾取、再主动回营，失败可复活重新进场。离场前提示地面遗留物将消失。

| 敌人 | 玩家能看见的预警 | 行为与对策 |
| --- | --- | --- |
| 灰棘猎犬 · 普通 | 压低前身，朝目标留一条短直线 | 接近后短扑，扑出后有收招；侧移后反击。 |
| 苔角守卫 · 精英 | 枝角发亮，地面出现宽扇形 | 慢速逼近，蓄力后扫击；绕到侧后方攻击。首个流水线生产对象。 |
| 裂木古王 · Boss | 抬臂显示圆形震地范围 | 近距离震地，远距离追击；半血后追加延迟较长的第二次震地，先躲再靠近。 |

怪物配置引用模型、半径、生命、移动速度、动作时长、伤害、经验及奖励表。预警开始时锁定方向或落点；玩家离开伤害区域应能避开。受击、击杀与清场独立结算，重复进入营地或清场回调不能再次发奖。

## 后续无限深渊

通关固定关卡后开放。每层用种子组合入口、战斗房、精英房和 Boss 房，生成后校验连通和可行走落点。玩家可以重试已解锁层，首次击败该层 Boss 才解锁下一层。失败保留已取得物品、退出当前层，从营地重开。存档保存最高完成层，首轮方案从入口重开单层。

层数决定遭遇预算、怪物等级和精英词缀池，高层逐步增加危险组合。同一词缀的冲突标签互斥；为攻速、密度、词条阶级设置上限，高层优先改变组合。固定种子复验布局与敌人组成，掉落按独立随机流结算，玩家死亡和刷新不能重复领取通关奖励。

## 后续图鉴与成就

首次击杀按怪物模板 ID 解锁条目，首次拾取按装备底材 ID 解锁；换装、分解、重复击杀保留发现记录。条目展示预览、首次发现地点、已知攻击或掉落来源。成就首批记录首次精英、首次传说、首次深渊通关。历史存档从已有装备与已记录进度补登可证明的条目。
