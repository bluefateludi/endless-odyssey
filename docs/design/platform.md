# 界面、存档与工程验收

## 玩家界面与存档

进入营地后显示出发入口、角色状态、背包与天赋；战斗 HUD 保留生命、经验、目标、普攻和顺劈。背包选中装备后显示属性对比、穿戴和分解。天赋树以分支和连线表示前置，用文字区分已点、可点、锁定。面板打开时暂停游戏时钟，关闭后再继续模拟；键盘焦点留在当前面板，避免点击按钮时角色同时攻击。

关键动作完成后在 IndexedDB 保存一致快照，含版本、等级与经验、金币材料、背包与穿戴实例、已点天赋及必要冷却。刷新从营地恢复。保存失败显示可重试状态，旧版或损坏存档需保留原始记录。首版地面掉落限本次关卡。存读档验收包含满包换装、洗点、传奇冷却、损坏记录及数据库写入失败。

## 工程支撑

| 系统 | 输入 → 输出 | 首版验收 |
| --- | --- | --- |
| 运行时 | 玩家意图、角色数据 → Three.js 场景与 Rapier 碰撞结果 | 固定步长模拟与渲染解耦，切出窗口或打开面板不会导致攻击连续补发。 |
| 配置与平衡 | 怪物、装备、词条、天赋、地图 → 可引用目录与统计报告 | 拒绝无效引用、天赋环路、非法权重与无法生成的词条组合；固定种子可复现。 |
| AI 资产流水线 | 规格、程序化建模或合法素材 → GLB、多视角预览、预算报告、资产注册表 | 记录来源和版本；预算超限时输出原因与截图，修正后再入库。游戏按已验收版本加载森林精英。 |
| 自动测试与发布 | 领域测试与浏览器操作 → 截图、测试结果、Vite 静态站点 | 在真实浏览器走通移动、躲招、击杀、升级加点、拾取换装、洗点、刷新恢复。资源路径需支持子目录。 |

可重复测试使用固定随机种子与独立存档。验收报告记录测试环境、实际通过项及未覆盖项；性能数据随渲染设备与分辨率记录。先追踪首场战斗时间、首件可用装备、首点天赋的伤害变化，再按实玩调整数值。
