## 范围与后续

首版以一张地图、三种敌人、普攻与顺劈为可玩内容。本轮交付的是单种精英从规格到入库的资产生产闭环，并支持现有 GLB 进入相同验收流程。其他三种主动技能、强化与重铸、无限深渊、图鉴，以及十种怪物的批量生产列入后续版本。生产包中的游戏引擎块包含 Three.js 和 Rapier，约 1 MB gzip；首次进入仍需加载这一块。目前验收针对桌面键鼠流程。


## 最终重复回归

在固定测试时钟下，浏览器仍通过键鼠操作并执行真实的物理步长、动作、命中和掉落逻辑。这样截图和机器负载不会改变玩家两次输入之间的战斗时间。正式游戏继续使用真实时钟。

本次执行 `npm run test:e2e -- --repeat-each=2`，三条用例各运行两次，结果为 **6/6 通过，约 3.2 分钟**。两次完整远征均从 1 级新档开始，击败 Boss 后回营，重载验明天赋与铁剑仍在。
